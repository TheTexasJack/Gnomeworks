# Gnomeworks: notes for Claude (v0.1)

A gnome-themed browser clicker game Nathan is building for Jarrett's shop, The Stoned Gnome.  Plain HTML, CSS, and JavaScript; no build step.  Live on GitHub Pages from `main`.

**Start every session here:** read [docs/HANDOFF.md](docs/HANDOFF.md), then [docs/TASKS.md](docs/TASKS.md), then whatever doc the work needs ([docs/DESIGNS.md](docs/DESIGNS.md) for the Packing Line, [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for code, [docs/ASSETS.md](docs/ASSETS.md) for art).

## Rules

- **Small steps, approval at each.**  Show Nathan a screenshot or short video before anything big goes live.
- **Commit straight to `main`.**  No branches or pull requests.  Pull before starting: other sessions (the cloud Claude, Mara) push to this repo too.
- **Every code change:** bump `GW.VERSION` in `js/config.js`, run `node tools/stamp.js`, add a `CHANGELOG.md` entry, run `node tools/smoke-test.js`, then commit and push.  Keep the docs current.
- **Every number lives in `js/config.js`.**
- **Writing in the repo:** two spaces after periods, no em dashes, no "not X, it's Y" phrasing.
- **Art:** approved full-size masters live in `art-masters/` and are never loaded by the game.  Game copies are small WebP files in `assets/`, made with `tools/art.py`.  Lore and the map live in `docs/lore/`; the map is generated by `tools/map/build_map.py`.
- **Game rules:** no gambling mechanics unless Jarrett asks, real taps only for anything rare, kid-friendly, phone first.
- Ideas are drafts until Nathan approves them.  He wants honest pushback, and his words followed exactly.
