# Assets

Game-ready art only (compressed WebP and the Twemoji SVGs).  The full folder map, processing commands, placement numbers, and lessons learned are in [docs/ASSETS.md](../docs/ASSETS.md).

## Quick spec for new art from Mara

* PNG with a real transparent background.  Check it on a dark background.
* Same painted style as the existing set: chunky shapes, warm brass and oak, light from the upper left.
* Sheets: a clear grid with real gaps between pictures, plus a list of names in reading order.
* Animated gnomes: static and action frames side by side in one image, feet on the same line, facing left toward their machine.
* Badges: gear-framed circle, head and shoulders, red-haired gnome.
* Hats: worn view, with none of the inside of the brim showing.
* Any text in the image gets proofread letter by letter.
