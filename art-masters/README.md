# Art masters (v0.2)

Full-size, approved source art, kept here as the backup.  **The game never loads anything from this folder.**  Claudia makes the small WebP copies in `assets/` from these with `tools/art.py` when a piece is integrated.

Rules:

- Only art Nathan has approved goes here.  Drafts stay out.
- Folder names match the work package numbers in [docs/art-style/PACKING-LINE-PRODUCTION-CHECKLIST.md](../docs/art-style/PACKING-LINE-PRODUCTION-CHECKLIST.md).
- File names are lowercase with underscores, no spaces or brackets, and say the layout, theme, and state.
